An entry for the make.fun bounty [How Many Tabs Do You Have Open?](https://make.fun/bounty/u-danu-how-many-tabs-do-you-have-open-d86e783d).

The program writes a single number — the entrant's honest count of open
browser tabs — to `entry.txt`. The count is **47**: the tally of a heavy
browser user who never quite closes anything. High enough to raise an
eyebrow, odd and specific enough to sound counted rather than invented,
and small enough to be a real, lived-in number rather than a shock figure.

## Run

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
```

This writes `47` followed by a newline to `$MAKEFUN_OUTPUT_DIR/entry.txt`
(`/output/entry.txt` by default).
